# Exceções de resolução de dependências

As resoluções abaixo são deliberadas e devem permanecer enquanto a cadeia direta ainda não expõe
uma versão compatível por resolução normal. Cada alteração exige `pnpm validate` e `pnpm audit:prod`.

| Pacote                   | Resolução | Motivo e compatibilidade                                                                                                                                                                                                                            | Remoção                                                                                                              |
| ------------------------ | --------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| `body-parser`            | `2.3.0`   | Corrige o alerta baixo transitivo do Express usado por `@nestjs/platform-express`; a API mantém o contrato atual.                                                                                                                                   | Remover quando a cadeia do Nest/Express resolver `2.3.0` diretamente.                                                |
| `brace-expansion` (`^2`) | `2.1.2`   | É a versão compatível com a API CommonJS exigida por `minimatch@9`, corrigindo o advisory aplicável ao caminho `TypeORM → glob → minimatch`. O advisory adicional que exige `5.0.8` fica em exceção formal, pois a versão 5 quebra esse consumidor. | Remover quando TypeORM/glob/minimatch resolverem uma versão corrigida e compatível sem override e repetir auditoria. |
| `brace-expansion` (`^5`) | `5.0.8`   | Corrige o advisory do caminho `minimatch@10` sem alterar o consumidor.                                                                                                                                                                              | Remover quando a cadeia resolver `5.0.8` diretamente.                                                                |
| `js-yaml` (`^5`)         | `5.2.2`   | Corrige o alerta alto da cadeia do Swagger sem alterar o contrato de documentação.                                                                                                                                                                  | Remover quando `@nestjs/swagger` resolver a versão corrigida diretamente.                                            |
| `postcss`                | `8.5.18`  | Corrige os alertas altos e moderados transitivos do Next.js; o build da aplicação web valida o processamento CSS.                                                                                                                                   | Remover quando o Next.js resolver uma versão igual ou superior diretamente.                                          |
| `sharp`                  | `0.35.0`  | Corrige o alerta alto transitivo do Next.js. O projeto não usa `next/image`; o build e o typecheck validam que a resolução continua instalável.                                                                                                     | Remover quando o Next.js resolver a versão corrigida diretamente e confirmar compatibilidade.                        |

Esses overrides não reduzem a severidade dos advisories. O gate continua lendo o grafo efetivamente
instalado e bloqueia qualquer advisory crítico ou alto sem exceção formal vigente em
[`audit-exceptions.json`](audit-exceptions.json).
